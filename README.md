<h3 align="center">✦ &nbsp;Aurora Ops &nbsp;·&nbsp; Flagship</h3>

<p align="center">
  <a href="https://github.com/Mr-Bathwal/aurora-ops-frontend">
    <img src="https://img.shields.io/badge/⭐_Aurora_Ops-View_Repo-A78BFA?style=for-the-badge&labelColor=0F1020" alt="Aurora Ops"/>
  </a>
</p>

<p align="center">
  <b>An AI console that runs LLM agents against real machines</b> — watch them reason, then read what they found.<br/>
  A fleet of specialist agents (health · logs · backup · auto-remediation) with an <b>orchestrator</b> that hears a<br/>
  symptom and routes it to the right agent. Each agent runs its own tools on your infrastructure and reports back in plain language.
</p>

<div align="center">

| | |
|:--|:--|
| 🤖 **AI stack** | LLM Agents · Multi-agent Orchestration · Tool-calling · Live reasoning traces |
| 🖥️ **Frontend** | Next.js 16 (App Router · Turbopack) · React 19 · TypeScript |
| 🌌 **Experience** | Three.js / React-Three-Fiber 3D scene · Framer Motion · Tailwind v4 |
| ⚡ **What it does** | Diagnose → reason → remediate across a live fleet of servers |

</div>
